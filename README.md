# Vrinda Store Annual Report 2022 – Project Description

The Vrinda Store Annual Report 2022 is an interactive Excel dashboard project created to analyze sales performance, customer behavior, and order trends for an online retail store. The dashboard provides a comprehensive overview of business operations by transforming raw sales data into meaningful visual insights that support data-driven decision-making.

The report includes important business metrics such as total sales, order count, order status, top-performing states, sales channels, and customer demographics. Interactive charts and slicers allow users to filter and analyze data by month, category, and sales channel, making the dashboard dynamic and user-friendly.

The dashboard highlights sales trends across different months, compares orders versus revenue, and identifies the top 5 states contributing to overall sales. It also provides insights into customer purchasing behavior by analyzing gender and age group distributions. Additionally, order status analysis helps track delivered, returned, refunded, and cancelled orders to evaluate operational efficiency.

## Key Features
- Interactive sales dashboard
- Monthly sales and order analysis
- Top-performing states visualization
- Customer age and gender insights
- Order status tracking
- Channel-wise sales analysis
- Dynamic filtering using slicers

## Tech Stack
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers & Interactive Dashboard Design
- Data Cleaning & Data Analysis
